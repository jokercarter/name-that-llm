## 3. 采集与统计口径

### 3.1 外部语料（`data/external/ntl_merged_external_large.parquet`）

过滤链，按顺序执行：标签必须逐字等于 18 类之一 → 词数 36–274（竞赛自身的真实区间）→ ASCII 占比 ≥0.85 → 去掉代码围栏/行首标题/`**` → 按小写去标点归一化后全局去重。**不做每类上限**，平衡留到采样时处理。

复算结果（`python -c` 读 parquet）：


`MANIFEST_LARGE.json` 与文件**逐字段一致**（行数、组数、中位词数、18 个类的计数、15 个来源标签全部对得上）。

### 3.3 吞吐口径（最关键的一条）

- 样本通过量 = **行数 × 折数**（每折训练 (k−1)/k，最后再全量重训一轮，合计正好 k 倍），仅对 1 epoch 成立。
- `0.216 s/样本`来自验证跑重训段：`623 s / (90 步 × 32 样本) = 0.216 s`。
- **这个数包含 6 次内层评估**（每 15 步一次、每次 192 行）。纯训练约 0.19 s；生产配置 `eval_every=200`，评估开销可忽略，所以用 0.216 外推 5 万条是**偏保守**的。
- `MFU 5.5%` 依赖"平均 padded 146.5 token"：用 Qwen3 分词器对 4,000 条实测（中位 129、p90 262、p99 328、384 处截断 0.22%），**不再是假设的 150**。

### 5.2 数据质量问题（P1）

**重复 id（已修复）**：过采样补齐的行沿用了源行的 `id`，导致 50k 文件里 `id` 不唯一（46,573 个唯一值 / 50,003 行）。当前管线只用位置索引，**不影响训练与提交**；但任何按 `id` 的 join 都会静默放大计数。

已在 `build_external_mix.py` 修复：重复行改用 `id_r<计数>` 后缀（同一行被抽中多次时计数递增）。重新构建后 `rows 50,003 / unique 50,003 / dup 0`。本地既有文件与正在运行的 Kaggle 任务用的是修复前的版本，未重建——保持与已跑结果一致，且 `id` 不参与训练。

**重复样本占 6.9%**：全部来自 5 个尾部类（`qwen3.8-max` 等语料只有 1,510–2,058 条）。它们同 `prompt_id`、必同折，所以不构成跨折泄漏；但同一段文本在训练折内出现两次，会让对应类的 OOF 略偏乐观（约影响 3–4 个类）。

### 5.3 外部语料许可（P1，非技术风险）

贡献最大的 `abdelghanyrageh/ntl-extra-merged`（约 1.3 万行）**没有描述、许可写的是 Other**。其余 14 个源为 CC BY 4.0 / CC BY-SA 4.0。若进前十需要开源方案，这一段的上游条款必须逐条复核；技术上无法从 Kaggle 页面推断其真实来源。

### 5.4 权重来源（P1）

`vodung020905/qwen3-1-7b` 是个人镜像，不是 Qwen 官方账号。文件结构是标准 HF 布局（config + 2×safetensors + tokenizer），但**无法验证权重是否被改动**。赛题允许公开预训练模型，镜像通常可接受；严谨做法是从官方发布重新上传一份自有数据集并核对 SHA。

### 5.5 不可验证项（P2）

| 项 | 状态 |
|---|---|
| 34 分 16 秒总墙钟 | 用户提供；我只能核对三段 fit 合计 26.4 min，余 7.8 min 归因于环境/安装/单测/CPU 阶段，未逐项计时 |
| 隐藏测试集"约 4,000 行"、public 40% / private 60% | 引自赛题页，本机无法验证 |
| batch 12 能拿回 10–15% MFU | **推断**，未实测；这也是当前 8 h 方案唯一的假设 |
| 外部语料标签正确性 | 只保证与 18 类字符串逐字一致，未做人工抽检 |
| 双卡每个 batch 的切分一致性 | 单元测试覆盖了索引切分，但实跑只验证了总量与最终 OOF，未逐 batch 比对 |

## 6. 结论

能在本机复算的数字（语料规模、类别分布、重叠、缺失、重复、参数量 52,199,706、OOF 0.4211、test 0.6035）**全部对得上**；出问题的都是**由假设推出来的时间数字**——MFU 0.18 那次估算把 9 小时说成了 3 小时，这是本次审计最主要的发现，已经用实测值替换并在文档里标注了来源。

尚未闭环的两件事：batch 12 的实际加速比（正在跑的生产任务会给答案），以及外部语料中 `Other` 许可那部分的来源。

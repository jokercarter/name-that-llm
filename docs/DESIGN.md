# PACT-18 设计说明

## 1. 问题与关键观察

任务是 18 类文本作者归属，指标为 balanced accuracy。公开方案（Code 区前十）都把问题当作「逐段独立分类 + 全局边际平衡」，分数卡在 0.559，而 Leaderboard 第一为 0.622。

三个来自数据本身的事实决定了方案空间：

1. **训练集是 18×150 的完整网格**：2,699 = 150×18−1；Claude(5)+GLM(2) 共 1,049 条（7×150=1,050）；Gemini 恰好 600 条（4×150）。
2. 因此 **同一 prompt 下每个模型至多出现一次**——这是一个簇内互斥约束，比 Sinkhorn 的全局边际强得多。
3. 测试集 prompt 与训练完全不重叠，但**测试池内部仍有簇结构**（同 prompt 的多段文本），可以在无标签条件下推断。

## 2. 为什么是「结构」而不是「更大的模型」

单个成员的 OOF 上限只有约 0.48（LoRA24），0.55+ 完全来自十余个异构成员的融合。继续加同类成员边际收益趋近于零。而结构约束是一个**尚未被使用**的信息源，且成本是毫秒级的组合优化。

模拟（18 类、每簇 18 条、每类恰好一次、logits = 正确类信号 + 噪声）：

| 每段 argmax | 簇内硬指派 | 增益 |
|---:|---:|---:|
| 0.389 | 0.410 | +0.021 |
| 0.509 | 0.548 | +0.039 |
| 0.566 | 0.624 | +0.058 |
| 0.603 | 0.687 | +0.084 |
| 0.654 | 0.748 | +0.094 |

+0.058 恰好覆盖 0.559→0.622 的差距量级。

但硬指派对聚类错误极度敏感：把一个 prompt 的 9 条混进另一个簇，准确率从 0.622 掉到 0.487。于是有了 PRISM 的松弛形式。

## 3. PRISM：容量约束的松弛指派

对大小为 m 的簇，构造代价矩阵：

- **主槽** K=18 列：`cost[r,c] = -log p_r(c)`
- **重复槽** K×K 列：`cost[r,c] = -log p_r(c mod K) + λ`

求解 `linear_sum_assignment`，每行取一个槽位，`pred = slot % K`。

- `λ=0`：允许重复，退化为带耦合的 argmax；
- `λ→∞`：硬指派，每类恰好一次；
- `λ≈1 nat`：最优折中。

模拟结果（干净簇 / 混入 4 条 / 混入 9 条）：

| 策略 | 干净 | 混 4 | 混 9 |
|---|---:|---:|---:|
| argmax | 0.564 | 0.554 | 0.551 |
| 硬指派 | 0.622 | 0.533 | 0.487 |
| **λ=1 松弛** | **0.628** | **0.565** | 0.541 |

即：松弛版吃到了硬指派的全部收益，同时把污染下的损失从 −0.14 压到 −0.01。工程上再加两道保险：

1. 只对 `2 ≤ m ≤ 18` 的簇启用（singleton 与超大簇直接 argmax）；
2. `confidence_threshold`：簇内平均相似度低于阈值时跳过。

## 4. 其余五个组件

| 组件 | 动机 | 做法 |
|---|---|---|
| 学习式聚类 | 公开方案用 TF-IDF + GLM 隐状态余弦，pair recall 仅 0.85，阈值三处不一致 | 用训练集的 `prompt_id` 构造同题/异题对，学习一个 n-gram 特征上的对角度量，相似度 = `<w⊙x_i, w⊙x_j>`，再平均连接聚类 |
| 风格不变表征 | 推理期中心化对 singleton 无效 | `stylegram.center_mode` 保留中心化孪生；数据层用「同 prompt 不同模型」作为天然平行语料（StyleDistance 思想） |
| 代理困惑度 | LLMDet 路线，前十名未使用 | 每类拟合 add-α 的 unigram+bigram LM，输出 18 维交叉熵 + rank/margin/entropy，再接多项 LR |
| 家族专家 | 只做 Claude 门，其余 13 类无专家 | 6 家族两级；专家只重写已预测家族内部的分布，外部数据只能进这一级 |
| 正字法护盾 | Sinkhorn 会把不可能类别的概率抬起来 | 从训练集自动发现「某家族几乎不出现的标记」（弯引号、双长破折号），后置对数惩罚 |
| SLD-EM 校准 | 固定 α 的 Sinkhorn 在 public/private 混合变化时不可控 | 用 EM 估计测试集类别先验再校正，Sinkhorn 作为兜底 |

## 5. 推理顺序

```
成员概率 → 温度缩放 → 对数概率融合 → SLD-EM → 家族专家 → 正字法护盾 → PRISM
```

PRISM 放在**最后**，保证最终输出一定满足结构约束；前面的每一步都在修改概率，PRISM 在这些概率上做联合解码。

## 6. 验证协议

1. **L0 组件 CV**：prompt-grouped 5 折，报告每类召回。
2. **L1 融合 held-out**：权重在 fold-out 上拟合，避免「用 OOF 调权重再用 OOF 评估」。
3. **L2 伪测试池**：从 held-out prompt 构造每 prompt k 段的池（k=1..18），并注入聚类噪声（split / merge），端到端比较策略。`simulate` 命令实现。
4. **L3 显著性**：按 prompt 做 cluster bootstrap，只有 CI 下界 > 0 的组件才进最终栈。

## 7. 已知局限

- 合成数据只复现结构性质与风格差异，不代表真实模型的指纹强度；本项目在合成数据上的绝对分数没有意义，**只有相对消融有意义**。
- 学习式聚类是线性对角度量，不是真正的双塔编码器；换成 bi-encoder 需要 torch，当前实现刻意保持零重依赖。
- 代理困惑度成员用的是 n-gram LM 而非神经 LM，信号弱于 LLMDet 原版，但完全离线、无额外权重。
- `experts` 用融合概率作为特征，属于 stacking；真实比赛中应改成用成员原始特征训练，避免信息损失。
